# 玉衡 v5.13.0

一个美股期权日内交易者自用的**研究、盯盘和纪律工具**。程序负责抓数据、存数据、回测、盯盘、按选定的规则提醒入场和出场、卡纪律；**判断由交易者自己做，下单永远手动**。

> - 程序对 moomoo **只读**（行情、持仓、成交），没有任何下单、撤单、改单代码。
> - 本仓库不构成投资建议，盈亏自负。回测结论都如实写在 `报告/` 和 `CHANGELOG.md` 里，**包括大部分想法扣掉成本后没有优势**。

## 能在什么系统上用

**macOS 和 Windows 都能用**（v5.7.0 起）；Linux 大部分能用。

| | macOS | Windows 10 / 11 | Linux |
|---|---|---|---|
| 回测、策略库、今日预案、仓位方案回测 | ✅ | ✅ | ✅ |
| 盯盘界面、控制台（网页） | ✅ | ✅ | ✅ |
| 控制台守护常驻程序（挂了自动重启、打开时清场） | ✅ | ✅（用 psutil） | ✅ |
| 策略提醒 / 纪律程序的弹窗 + 提示音 | ✅ 系统弹窗 + 通知 | ✅ 重要的：置顶对话框；一般的：右下角系统通知；mp3 提示音用 PowerShell 播放 | ⚠️ notify-send + paplay / aplay（有就用） |
| 运行时不让电脑睡眠 | ✅ caffeinate | ✅ 系统接口 | — |
| 一键启动 | `玉衡5.0.app`（`程序/build_app.sh` 生成） | 双击 `玉衡5.0.bat` | 命令行 |

说明：
- **作者自己用的是 macOS**；Windows 部分按 Windows 的方式写好、在 Mac 上模拟测试过（进程查找用带空格和反斜杠的 Windows 路径测过），**还没在真的 Windows 电脑上跑过**。在 Windows 上遇到问题欢迎开 Issue。
- M 芯片的 Mac 一定要用**原生模式**运行 Python（命令前加 `arch -arm64`），否则 numpy 会报错；用 App 启动时已经自动处理。
- Windows 上手动跑命令前先 `set PYTHONUTF8=1`（PowerShell：`$env:PYTHONUTF8=1`），让 Python 用 UTF-8 读写中文文件；用 `玉衡5.0.bat` 启动时已经自动设好。

## 有什么功能

**决策思路**按《交易的本质》三个问题：① 凭什么有优势（回测 / 策略库）；② 值不值得冒险（每笔多少、最差多少、仓位方案）；③ 怎么兑现（写成「如果……就……」的纪律，锁定后由程序提醒和检查）。

| 模块 | 作用 |
| --- | --- |
| 日内策略库 `程序/intraday.py` | 1 分钟K（2019 起）× **三层**：12 条入场（含个人策略 A 爆发、个人策略 B VWAP 回踩、开盘区间突破、VWAP 收复、缺口回补 / 延续、假突破收回……，**每条都分做多 / 做空**）× 7 种止损 × 8 种止盈（2R、前高 / 前低、斐波那契 1.0 / 1.272 / 1.618 / 2.0 / 2.618、拿到收盘）。换算成期权（平值、约 3 天到期，Black-Scholes 逐根重算，按交易时间扣时间价值，扣价差），带随机入场对照，样本外 2024 起 |
| 仓位方案回测 `程序/sizing.py` | 只做 1 张 / 每笔固定美元风险 / 金字塔加仓 / 分批出场 / 广撒网滚仓 + 熔断（连亏停手、盈利回吐停手）；**只用 2019–2023 挑组合、2024 起检验**（真正的留出检验） |
| 盘前分析 `程序/premarket.py`（控制台 `/pre`） | 每只股票一块的热力图（大小 = 成交额，颜色 = 盘前涨跌）；点开看今天会走成哪种形态的概率饼图、每种形态下回测最好的组合和仓位（事后看，和随机比）、今日预案的建议 |
| 今日预案 `程序/playbook.py` | 按今天的开盘类型（大幅低开 / 低开 / 平开 / 高开 / 大幅高开）和方向，给每只股票写「如果……就……」；盘前读实时跳空和平值期权 Delta / Gamma，算止损一次每张约亏多少 |
| 策略提醒 `程序/stratwatch.py`（核心 `程序/stratlive.py`） | 每天给观察名单里每只股票选定「入场 + 止损 + 止盈」和仓位方案，盘中每分钟检查：入场（CALL 还是 PUT、正股入场 / 止损 / 止盈价、建议合约、期权止损 / 止盈价、该进几张）、出场、加仓、走一半、砍、熔断 → 弹窗 + 提示音，并记进当天的记录文件。规则和回测是同一套代码 |
| 纪律程序 `程序/guard.py` | 按当天锁定的纪律（笔数、单日亏损、名单、方向、最晚开仓、认错价）每分钟查成交和价格，违反就弹窗 |
| 盯盘界面 `程序/dash.py`（网页 8767） | 观察名单、大字结论卡（选了策略就按选定的策略说）、K 线、期权墙、资金流向、持仓的作战面板；能回放任意一天；能在本机改选定策略 |
| 策略库页面（控制台 `/lib`） | 分成六块：今日预案 / ① 入场 / ② 止损 / ③ 止盈 / ④ 仓位管理 / 日线背景（`程序/stratlib.py` 的日线 34 条策略只当背景） |
| 控制台 `程序/console.py`（网页 8760） | 守护所有常驻程序、状态灯、工具按钮（重算策略库、回填 K 线……）；进程、弹窗、防睡眠这些和系统有关的事都在 `程序/osutil.py` |
| 盘感训练 `程序/trainer.py`（8765） | 历史 K 线盲测练习 |
| Discord 机器人 `程序/bot.py` | 定时任务：新闻归档、盘前报告、重大新闻推送、收盘复盘（K 线入库 → 重算策略库 → 重算仓位回测 → 写下一天的预案）、周报 |

研究报告在 `报告/`。

## 给 AI 的安装步骤（照着做就能装好）

> 这一节是写给帮你安装的 AI 助手（例如 Claude Code）看的，也适合自己照着敲。项目根目录里的 `CLAUDE.md` 是给 AI 的完整使用说明（每天的流程、纪律设置格式、哪些事绝对不能做），装好后让 AI 先读它。

### 0. 先确认这些

- [ ] **moomoo 账户**，并且装了 **moomoo OpenD**（moomoo 官网 OpenAPI 页面下载，Mac / Windows / Linux 都有），登录后监听 `127.0.0.1:11111`。要有美股行情权限；读期权链需要美股期权行情权限。
- [ ] **Python 3.10 或更新**（作者用 3.13）。Mac 上检查：`python3 --version`。
- [ ] 能访问 PyPI（装依赖）和 Yahoo Finance（部分数据的备用来源）。
- [ ] 不需要也不要给程序任何交易密码：程序只连行情和查持仓。

### 1. 下载代码

```bash
git clone https://github.com/dali114514/yuheng.git 玉衡5.0
cd 玉衡5.0
```

文件夹名可以随便起；以下命令都在**项目根目录**（有 `CLAUDE.md` 的那一层）里运行。路径里有中文（`程序/`、`数据/`、`报告/`），终端和编辑器要用 UTF-8。

### 2. 建 Python 环境、装依赖

macOS：

```bash
python3 -m venv 程序/.venv
程序/.venv/bin/python -m pip install --upgrade pip
程序/.venv/bin/python -m pip install -r 程序/requirements.txt
touch 程序/.venv/.installed
```

Windows：**直接双击根目录的 `玉衡5.0.bat`**——第一次会建环境、装依赖、从示例复制出 `设置.json`，然后打开控制台。想手动装（PowerShell）：

```powershell
$env:PYTHONUTF8=1
py -3 -m venv 程序\.venv
程序\.venv\Scripts\python -m pip install --upgrade pip
程序\.venv\Scripts\python -m pip install -r 程序\requirements.txt
```

下面的命令统一写成 `PY 程序/xxx.py`，把 `PY` 换成：

| 系统 | 换成 |
|---|---|
| M 芯片 Mac | `arch -arm64 程序/.venv/bin/python` |
| Intel Mac / Linux | `程序/.venv/bin/python` |
| Windows | `程序\.venv\Scripts\python`（路径里的 `/` 换成 `\`） |

### 3. 建设置文件

```bash
cp 设置.example.json 设置.json        # Windows：copy 设置.example.json 设置.json
```

示例设置里所有密钥都是空的，需要密钥的功能默认是关的。最少只要改两处（用 Python 改，别手工拼字符串，免得把 JSON 弄坏）：

```bash
PY - <<'EOF'
import json
p = "设置.json"
d = json.load(open(p, encoding="utf-8"))
d["moomoo"].update({"启用": True, "OpenD地址": "127.0.0.1", "OpenD端口": 11111})
d["工作流"]["研究名单"] = ["QQQ", "SPY", "NVDA", "AAPL", "TSLA"]   # 要存 K 线、做回测的股票；留空 [] = moomoo 自选里全部美股
json.dump(d, open(p, "w", encoding="utf-8"), ensure_ascii=False, indent=2)
EOF
```

（Windows PowerShell 没有 `<<'EOF'`：把中间几行存成 `setup.py` 再运行 `PY setup.py`。）

其他可选功能（Discord、Grok、网站分享、E 盘同步）见下面「设置.json 怎么填」。**`设置.json` 有密钥，永远不要提交到 git**（`.gitignore` 已经排除）。

### 4. 检查能不能连上 moomoo

```bash
PY 程序/review.py --check
```

应该看到 OpenD 连上、能读到行情和 K 线（这一步只读，不写任何数据）。连不上先看 OpenD 是否已登录、端口是不是 11111。

### 5. 建 K 线库（第一次要几十分钟到几小时）

```bash
PY 程序/review.py --backfill        # 日线 10 年、5 分钟最多 1 年、1 分钟：研究名单补一年 → 程序/data/history.db；完了自动建盘感引擎缓存
PY 程序/longhist.py                 # 可选：1 分钟K从 2019 年补起 → 程序/data/history_long.db（几小时，可以中断后接着跑）
```

moomoo 对历史 K 线有额度限制（每 30 天能拉的股票数），研究名单别一次放太多。不跑 `longhist.py` 也能用，但日内策略库的样本内（2019–2023）会是空的，预案大多挑不出东西。

### 6. 生成研究结果

```bash
PY 程序/cold.py --full              # 导出冷数据（数据/冷数据/），给人和 AI 读
PY 程序/stratlib.py                 # 日线策略库（约 10 秒）
PY 程序/intraday.py                 # 日内策略库（约 2 分钟，多进程）
PY 程序/sizing.py                   # 仓位方案回测（约 2 分钟）→ 报告/仓位方案回测_<日期>.md
PY -c "import sys; sys.path.insert(0, '程序'); import playbook; playbook.build(live=True)"   # 今日预案（要 OpenD）
```

以后这些由收盘复盘自动重跑（见「每天怎么用」）。

### 7. 启动

**macOS：**

```bash
zsh 程序/build_app.sh               # 生成 玉衡5.0.app（本机签名、玉衡图标）
open 玉衡5.0.app                     # 以后双击它
```

App 会打开控制台（http://127.0.0.1:8760），由它启动并守护：纪律程序、热数据、盯盘界面（http://127.0.0.1:8767）、早盘监测、策略提醒、Discord 机器人（设置里开了才启动）。
⚠️ **每次打开 App 会先关掉所有正在跑的 `程序/` 进程再重开**（干净启动）；测试时别在 App 开着的时候另外手动起同名程序。

**Windows：**

双击 `玉衡5.0.bat`。它会在后台启动控制台（不留黑窗口），几秒后浏览器打开 http://127.0.0.1:8760；控制台再启动并守护纪律程序、热数据、盯盘界面、早盘监测、策略提醒、Discord 机器人（设置里开了才启动）。输出写在 `报告/控制台窗口输出.txt` 和 `报告/控制台日志.txt`。
⚠️ 和 Mac 一样，**每次启动会先关掉所有正在跑的 `程序/` 进程**（干净启动）。

第一次弹提醒时 Windows 可能问要不要允许 PowerShell 发通知，选允许。

### 8. 装好后验证

```bash
PY 程序/stratwatch.py --test 2026-10-30 NVDA       # 回放某一天：没选策略时会说「预案没挑、也没手选：不提醒」，不报错即可
curl -s http://127.0.0.1:8767/api/version          # 盯盘界面在跑
```

## 设置.json 怎么填

`设置.example.json` 里每一节都有「说明」字段。常用的：

| 一节 | 作用 | 要不要填 |
|---|---|---|
| `moomoo` | OpenD 地址、端口、自选分组 | **必填**（默认 127.0.0.1:11111） |
| `工作流 → 研究名单` | 存 K 线、做回测的股票 | 建议填 |
| `预案 → 行情风险` | 大盘（QQQ）每种行情下的每笔最多张数 / 笔数 / 单日亏损上限（只能比纪律更严） | 可选 |
| `策略提醒` | `模式`：提醒 / 影子（只记录）/ 关 | 可选，默认「提醒」 |
| `盘中C2`、`形态监测` | 早盘监测、形态识别的模式和参数 | 可选 |
| `滚仓` | 广撒网滚仓持仓面板的参数 | 可选 |
| `盯盘界面 → 共享给Tailscale` | 让同一 Tailscale 网络里的设备打开盯盘界面（只能看，不能改） | 可选，默认关 |
| `Discord机器人` | 机器人令牌、频道；定时任务都靠它 | 想要自动盘前报告 / 收盘复盘 / 新闻推送就要填 |
| `重大新闻推送` | 快讯推到 Discord | 需要 Discord |
| `Grok盘前` | xAI Grok API 密钥，盘前读推特（按用量收费） | 可选 |
| `Reddit散户` | 散户热度 | 可选 |
| `网站分享` | Cloudflare Pages 发布报告网站 | 可选 |
| `存储` | 同步到局域网另一台电脑 | 可选 |

不用的功能把 `启用` 设成 `false` 就行。

**每天的纪律设置**不在 `设置.json` 里，在 `数据/今日/<日期>/纪律设置.json`（盘前报告自动建草稿）。格式见 `CLAUDE.md` 第五节，主要字段：观察名单（每只的方向、认错价、可选的 `策略`：`{"入场": "B", "止损": "time11", "止盈": "close"}`）、限制（笔数、单日亏损、每笔张数、最晚开仓）、`仓位`（`{"方案": "risk100", "熔断": {"连亏停手": 2, "回吐停手_美元": 200}}`）、`状态`（草稿 / 已锁定，锁定后才弹窗）。入场 / 止损 / 止盈的 id 见 `程序/intraday.py` 的 `STRATS` / `STOPS` / `TARGETS`。

## 每天怎么用

时间都是美东。

| 时间 | 发生什么 | 谁做 |
|---|---|---|
| 4:00–20:00 | 新闻、推特、Reddit 每 20 分钟归档；重大新闻马上推 Discord | 机器人自动 |
| 8:45 | 盘前报告 + 今日预案（读实时跳空和期权）+ 纪律设置草稿 | 机器人自动（或手动 `PY 程序/today.py --full`） |
| 开盘前 | 和 AI 讨论（说「开始今天」）：定观察名单、每只的策略、仓位方案、限制 → **锁定** | 你 + AI |
| 9:31–16:00 | 纪律程序每分钟检查；策略提醒每分钟检查入场 / 出场；盯盘界面看结论 | 程序自动 |
| 16:20 | 收盘复盘：K 线入库（会补上程序没开那几天）、成交同步、重算策略库和仓位回测、写下一天的预案 | 机器人自动（或手动 `PY 程序/review.py`） |
| 收盘后 | 对照 `数据/今日/<日期>/策略提醒.md` 和成交写复盘 | 你 + AI |

用 AI（例如 Claude Code）时，在项目根目录打开它，它会读 `CLAUDE.md`，按里面的规矩做事：不下单、不打印密钥、不改数据库、纪律锁定后不因为盘中情绪放宽、不编数字。

## 常见问题

- **M 芯片 Mac 报 numpy / 架构错误**：命令前加 `arch -arm64`；用 App 启动时已经自动处理。
- **「OpenD 没连上」**：确认 OpenD 已登录、`设置.json → moomoo` 的地址端口对、没有别的程序占用连接数。
- **策略库 / 预案是空的**：K 线不够。先跑第 5 步，尤其是 `longhist.py`（样本内 2019–2023 要靠它）。
- **K 线缺了几天**：收盘复盘会从上次入库那天起补（1 分钟K最多 30 天）；手动补：`PY 程序/review.py`。
- **弹窗没出来**：纪律设置要「已锁定」；`设置.json → 策略提醒 → 模式` 要是「提醒」；Windows 上看看「设置 → 系统 → 通知」里有没有关掉 PowerShell 的通知。
- **Windows 上中文乱码 / 读设置报错**：手动跑命令前 `set PYTHONUTF8=1`；用 `玉衡5.0.bat` 启动时已经自动设好。
- **端口**：8760 控制台、8765 盘感训练、8767 盯盘界面、11111 OpenD。

## 如实说

这个项目测过的大部分想法扣掉成本后都没有优势：

- 形态（信号K、组合K、双顶双底、震荡突破）之后往形态方向走的比例都在 48%–52%；扫流动性反转、三次触碰、日线择时策略相对持有全部为负。
- 日内策略库：全部股票合起来，没有一组「入场 + 止损 + 止盈」样本内外都赚；随机入场换成期权每笔约 −2% 到 −8%。
- 仓位方案回测：**按开盘类型挑组合这套办法，在没看过的数据上不赚钱**（样本内每笔为正、样本外为负）；仓位方案只改变亏多少、回撤多深，改变不了正负。
- 所以策略提醒是**执行工具**（按你选的规则提醒、帮你守纪律、把每一笔记下来），不是赚钱信号。要判断你选的策略有没有用，得按真实交易记满 40 天以上再看。

详见 `CHANGELOG.md` 和 `报告/`。
