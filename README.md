# 玉衡 v5.6.0

一个美股期权日内交易者自用的**研究和纪律工具**（macOS + moomoo OpenD）。程序负责抓数据、存数据、盯盘、卡纪律；判断由交易者自己做，**下单永远手动**。

> 程序对 moomoo **只读**（行情、持仓、成交），没有任何下单、撤单代码。本仓库不构成投资建议，盈亏自负。

## 有什么

| 模块 | 作用 |
| --- | --- |
| 控制台 `程序/console.py`（网页 8760） | 守护所有常驻程序，状态灯、工具按钮、设置 |
| 策略库 `程序/stratlib.py`、`程序/intraday.py`（控制台 `/lib`） | 日线：34 条策略 × 七种行情 × 13 种止损；日内：1 分钟K × 10 条策略 × 9 种止损，换算成期权收益，带随机入场对照 |
| 今日预案 `程序/playbook.py` | 按《交易的本质》三个问题（有没有优势 → 值不值得冒险 → 怎么兑现），按开盘类型和行情写「如果……就……」 |
| 纪律程序 `程序/guard.py` | 按当天锁定的纪律每分钟查成交和价格，违反就弹窗 |
| 盯盘界面 `程序/dash.py`（8767） | 观察名单、结论卡、K 线、期权墙、作战面板（吉凶字） |
| 盘感训练 `程序/trainer.py`（8765） | 历史 K 线盲测练习 |
| Discord 机器人 `程序/bot.py` | 盘前报告、新闻归档、收盘复盘、周报 |

研究报告在 `报告/`（回测结论都如实写了，包括没用的）。

## 安装

1. macOS（M 芯片要用原生模式），Python 3.9+，moomoo OpenD 开在 11111 端口。
2. 双击 `玉衡5.0.command`（第一次会建虚拟环境、装依赖）。
3. 把 `设置.example.json` 复制成 `设置.json`，填自己的密钥（Grok、Discord 等，不用的功能留空）。
4. `zsh 程序/build_app.sh` 生成 `玉衡5.0.app`，以后双击它。

不包含：K 线库、成交记录、个人设置和日志（`程序/data/`、`数据/`、`设置.json` 都不在仓库里）。

## 如实说

这个项目测过的大部分想法扣成本后都没有优势：形态、扫流动性、三次触碰、日线择时策略相对持有全部为负；日内随机入场换成期权每笔约 −2% 到 −8%，明显好于随机的只有少数「大幅低开」的日子。详见 `CHANGELOG.md` 和 `报告/`。

更新记录：[`CHANGELOG.md`](CHANGELOG.md)
