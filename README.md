# 期权价差机器人（moomoo OpenAPI 版）

用「期权坤哥」视频里的规则，自动在 SPY / QQQ 上做 **牛市看涨价差 / 熊市看跌价差**：

| 环节 | 规则 | 出处 |
|---|---|---|
| 标的 | 只做 SPY、QQQ（流动性最好） | 「流动性是第一条」 |
| 看涨信号 | 站上 MA120 且 RSI ≤ 35（回调超卖）；或 MA5>MA10>MA20>MA60 多头排列 | 「散户只看 MA + RSI」「多头排列做趋势」 |
| 看跌信号 | 跌破 MA120 且 RSI ≥ 65；或空头排列 | 同上，反过来 |
| 策略 | 看涨 → Bull Call Spread；看跌 → Bear Put Spread | 「新手先学 Bull Call Spread」「风险不到 100 块的垂直价差」 |
| 到期日 | 30–60 天，优先 45 天 | 「别买两周内到期的」「选长一点的 DTE」 |
| 合约 | 买入腿 Delta 0.25–0.55，两腿间距 ≤ $5，净支出 ≤ 预算，盈亏比 ≥ 1 | 「Delta + 权利金双指标法」 |
| 止盈 | 赚到最大盈利的 50% | 「50% 止盈」 |
| 止损 | 价差价值跌掉 50% | 「止损提前设好」 |
| 时间 | 剩 14 天平仓 | 「最后两周 Theta 加速」 |
| 仓位 | 同时最多 1 组 | 「三三原则」（50 块只够 1 组） |
| 日志 | 每笔都记进 `journal.csv` | 「写交易日志、复盘」 |

它是**低频**系统：信号用日线，一般几天到几周才出一次手，每 15 分钟检查一次持仓。

> **从仓库克隆下来之后（比如在 Mac 上）**：真实的 `config.toml` 不在仓库里（里面有账户 ID）。先复制一份：
> `cp config.example.toml config.toml`，再把 `sim_account` 改成你自己的模拟账户 ID（`moomoo sim account list` 查看）。
> Mac 上的虚拟环境路径是 `.venv/bin/python`，`start_console.bat` 只用于 Windows。

## 先读这段：50 块钱的真实情况

- **50 澳元 ≈ 30 多美元。** 一组 SPY 价差最便宜也要 20–30 美元，所以你的账户**只够同时做 1 组**，而且**一组就是你账户的大约 90%**。坤哥自己的规则是单笔不超过账户 2%，这里完全做不到。请把这 50 块当学费，目标是跑通流程，不是赚钱。
- 30 美元预算只能选到「买入 Delta 约 0.25–0.3、间距 $1」的价差：最多亏约 $27，最多赚约 $70，**胜率大约只有 25–30%**。连亏几次很正常（视频里那张「低胜率策略」表格讲的就是这个）。
- 每张合约都有手续费。开仓 2 张、平仓 2 张，一共 4 次。去 moomoo app 查清美股期权费率，填进 `config.toml` 的 `fee_per_contract`。
- 你在美股期权行业工作。**先确认公司的个人交易合规规定**（报备账户、预先审批、禁止交易的标的等），再下真钱。

## 第 1 步：moomoo 账户准备（在手机 app 里做）

1. **入金并换汇**：用澳洲银行卡入金澳元，再在 app 里「换汇」换成美元。期权只能用美元买。
2. **W-8BEN**：开户时一般已经填过。没填的在「账户 → 税务表格」里补上。
3. **开通美股期权权限**：「我的 → 账户 → 期权交易权限」申请美股期权，做完问卷。
   - ⚠️ **价差（两条腿，一买一卖）通常要比单纯买 call/put 高一级的权限**，有的券商还要求开融资（保证金）账户。以 app 里显示的级别说明为准。**没有价差权限，这个机器人的实盘单会被拒**，只能先用模拟盘。
4. **模拟盘**：app 里「模拟交易」打开美股模拟账户。机器人默认就是下到这个模拟账户里。

> 如果 `python -m venv .venv` 报 `ensurepip` 错，就改用：
> `python -m venv --without-pip .venv` 然后 `python -m pip --python .venv\Scripts\python.exe install -r requirements.txt`

## 第 3 步：moomoo CLI（行情 + 模拟盘都靠它，已经装好并登录）

在你这台电脑上，OpenD 的 API 拿不到美股实时行情，也看不到模拟账户，所以机器人改成：

| 用途 | 走哪条通道 |
|---|---|
| K线、期权链、期权买卖价和 Delta | **moomoo CLI**（OAuth 登录） |
| 模拟盘下单 | **moomoo CLI** → 模拟账户（ID 填在 `config.toml` 的 `sim_account`）（US Margin Account [Paper Trading]） |
| 实盘下单（`--live`） | OpenD / moomoo 桌面端 API，端口 `11112` |

- CLI 装在 `%LOCALAPPDATA%\MoomooCLI\bin\moomoo.exe`，路径在 `config.toml` 的 `[cli]` 里。
- **授权会过期。** 出现「未登录或授权过期」时，在 PowerShell 里重新运行：
  `& "$env:LOCALAPPDATA\MoomooCLI\bin\moomoo.exe" auth login`
- 如果遇到 DNS 报错（`getaddrinfow`），先运行 `$env:GODEBUG = "netdns=go"` 再登录。机器人自己调用 CLI 时已经自动加上了这个设置。
- 模拟盘不需要打开 OpenD。**只有实盘才需要 moomoo 桌面端开着并且已「解锁交易」。**

## 第 5 步：扫描（只看不下单）

```powershell

```

输出每个标的的信号、MA/RSI 数值，以及选中的价差（腿、成本、最大盈亏）。没有信号时，它会**演示**一下如果做牛市价差会选哪组。**scan 永远不会下单。**

## 第 6 步：模拟盘跑起来

```powershell
.\.venv\Scripts\python run.py once     # 跑一轮
.\.venv\Scripts\python run.py auto     # 每 15 分钟一轮，Ctrl+C 停止
.\.venv\Scripts\python run.py status   # 看持仓 / 挂单
```

- 只在美东时间 **09:45–15:45** 下单，窗口外只分析不下单。想在休市时测试下单流程，可以加 `--anytime`（仅模拟盘可用）。
- 模拟盘不支持组合单，所以价差是**分两条腿下**的：开仓先买保护腿，成交后再卖另一条腿；平仓先买回卖出腿，再卖出保护腿。两条腿都用「可立即成交」的限价（买按卖一价、卖按买一价）。第一条腿 30 秒内没成交就撤单，第二条腿不下。
- 因为按对手价成交，**预算也按对手价算**（`budget_on_worst = true`）。报价价差宽的时候（盘前、周末、大跌后）很可能「找不到预算内的价差」，这是正常的。
- 实盘（OpenD）用组合单，挂在中间价，**30 分钟没成交自动撤单**。
- 所有动作记在 `journal.csv`，可以用 Excel 打开复盘。

## 历史回测

```powershell
.\.venv\Scripts\python run.py backtest
```

第一次运行会把 2009 年以来的 SPY、QQQ、VIX 日线下载到 `backtest/data/`，之后直接用缓存。结果写入 `backtest/results.json`，控制台会读取这个文件。

**这是近似回测**：没有历史期权报价，期权价格是用 VIX 当隐含波动率、按 Black-Scholes 公式估算的，没有考虑波动率偏斜。信号、选合约、止盈止损都直接调用机器人自己的代码。

**2026-11-22 的回测结论（2010-01 → 2026-11）：**

| 场景 | 交易笔数 | 胜率 | 累计 | 平均每笔 |
|---|---|---|---|---|
| 当前规则（含 $1/张手续费 + 买卖价差） | 103 | 32% | −$804 | −$7.8 |
| 去掉手续费 | 162 | 32% | −$1,026 | −$6.3 |
| 再去掉买卖价差（只看信号） | 211 | 39% | +$512 | +$2.4 |
| 只看信号，且不受 $28 预算限制 | 209 | 53% | +$4,927 | +$23.6 |
| **对照组：不看信号、永远做多** | 265 | 63% | +$12,140 | **+$45.8** |

1. **按 $28 预算，这套规则在历史上是亏钱的。** 手续费加上买卖价差，吃掉了每笔 $20 多投入里的很大一部分。按 $28 熔断线，**2010 年 2 月就会触发熔断**。
2. **2019 年以后几乎没有交易。** SPY 价格涨上去之后，$28 预算基本买不到 Delta ≥ 0.25 的价差。
3. **MA/RSI 信号没有带来择时优势。** 在没有成本、没有预算限制的条件下，按信号做平均每笔 +$23.6，"不看信号、永远做多"是 +$45.8。这段历史里的盈利主要来自美股长期上涨，信号反而让收益变差了。
4. 换 RSI 阈值、把预算提到 $50 或 $100，结果都是亏损（见控制台里的参数敏感性表格）。

## 信号改进评估（`run.py research`）

方法：样本内 2010–2017 用来比较，**样本外 2018–2026 用来验证**；候选信号都是公开常见的规则，用默认参数，没有拿这份数据调参。两种检验：
- ① 信号出现后，标的未来 30 个交易日的涨跌（不涉及期权）；
- ② 完整的期权价差回测。

对照组是"永远做多"。结果存在 `backtest/research.json`。

**检验①：相对"永远做多"的超额收益（30 日，SPY+QQQ）**

| 信号 | 样本内 | 样本外 |
|---|---|---|
| 现有规则（MA120 + RSI14，多空都做） | −1.49% | −1.77% |
| 现有规则，只做多 | −0.60% | −0.51% |
| 收盘 > MA200 | −0.40% | −0.19% |
| MA50 > MA200 | −0.24% | −0.10% |
| 收盘 > MA200 且 RSI(2) < 10 | +0.42% | −0.13% |
| 收盘 > MA200 且收盘 < MA10 | 0.00% | +0.36% |
| **VIX ≥ 25** | **+1.53%** | **+3.57%** |
| **只看 RSI14 ≤ 35（不管趋势）** | **+3.02%** | **+2.55%** |

**检验②：期权回测，平均每笔（样本内 / 样本外）**

| 信号 | 纯信号（无成本） | 含成本、不限预算 | **你的实际预算（$30）** |
|---|---|---|---|
| 现有规则 | +$14 / +$31 | +$4 / −$2 | −$8.6 / −$5.9 |
| 永远做多（对照） | +$41 / +$50 | +$25 / +$19 | −$7.5 / −$8.1 |
| **只看 RSI14 ≤ 35** | **+$85 / +$61** | **+$70 / +$26** | −$0.4 / −$15.7 |
| VIX ≥ 25 | +$28 / +$65 | +$12 / +$23 | −$6.5 / −$10.5 |

**结论：**
1. **现有规则最大的问题出在 MA120 过滤。** "跌破 MA120 且超卖"恰恰是历史上反弹最好的入场点，但现有规则把它排除了。做空那一侧也在亏钱。
2. **"只看 RSI14 ≤ 35、只做多"是唯一在两段数据、两种检验里都跑赢对照组的规则。** 但每段只有 25–37 笔交易，样本小，可信度中等偏低。
3. **按 $30 预算，任何信号都是亏的。** 问题出在资金规模：手续费和买卖价差太重，而且行权价间隔太粗，选不到合适的价差。换信号解决不了这个问题。

## 小账户回测：$50 + 7:3 规则（`run.py small`）

设定：$50 起步、全仓、只做指数（SPY/QQQ）看涨，**+70% 止盈 / −30% 止损**，资金滚动计算，亏到买不起就算"出局"。2010–2024 每个月初各起步一次、每次跑 2 年，共约 180 个起点。结果存在 `backtest/small_account.json`。

| 方案 | 默认成本 | 价差减半 + $0.65 手续费 | 零成本（理想上限） |
|---|---|---|---|
| 单买一张 Call · 空仓就买 | 出局 100% | 出局 100% | 出局 99% |
| 单买一张 Call · RSI14 ≤ 35 | 出局 100% | 出局 99% | 出局 95% |
| $1 宽牛市价差 · 空仓就买 | 出局 100% | 出局 93%，赚钱 7% | 出局 44%，中位数 $129 |
| **$1 宽牛市价差 · RSI14 ≤ 35** | 出局 99% | **出局 79%，赚钱 19%** | 出局 23%，中位数 $143 |

**结论：**
1. **单买便宜期权，在任何成本假设下都会出局。** $50 只买得起 Delta 0.02–0.06 的合约，胜率只有 7–17%，远低于 7:3 需要的 30% 保本线。"−30% 止损"实际平均亏 −63%，因为便宜期权的买卖价差宽，而且一天之内就能跌掉大半。
2. **价差结构本身是成立的**：成本为零时，RSI14 ≤ 35 的价差有 75% 的起点能赚钱。
3. **真正把账户拖垮的是交易成本。** 每笔只投入 $20–30，一来一回的买卖价差加手续费就占了 15–20%，把 −30% 的止损空间吃掉了一大半。成本哪怕只减半，出局率仍然有 79%。
4. 价差方案的"出局"一般发生在剩 $15–20 的时候，也就是剩下的钱买不起下一组价差，不是亏到 0。

## 杰明价格行为打法回测（`run.py pa`）

用 SPY、QQQ 的**日线**开高低收和成交量（2010–2026），把「黑板干货」系列里的 5 套打法写成规则（详见 `optbot/pa_backtest.py` 开头的注释）。统一的风控是：**信号次日开盘入场，止损放在结构点外再加 0.5 ATR，目标 2R，最多持有 20 天**。结果用 R 倍数统计（1R = 这笔交易的风险），2018 年以前算样本内、以后算样本外。

| 打法 | 笔数 | 胜率 | 平均每笔 R（全部 / 样本内 / 样本外） | 换算成 ATM 期权：平均 / 中位数 |
|---|---|---|---|---|
| 趋势回踩 MA20 | 299 | 40% | +0.03 / +0.04 / +0.01 | −3% / −25% |
| 假突破 / 流动性扫荡 | 651 | 33% | −0.07 / −0.02 / −0.10 | −7% / −25% |
| 投降反转（抄大底） | 17 | 41% | −0.28 / +0.44 / −0.58 | −14% / −29% |
| RSI 画 W 底 / M 顶 | 93 | 37% | −0.05 / −0.27 / +0.14 | −10% / −33% |
| 波动压缩后大 K 突破 | 7 | 29% | −0.25 | −37% / −46% |
| **对照：只要空仓就做多** | 648 | 51% | **+0.17 / +0.24 / +0.12** | +5% / −20% |

**结论：**
1. **5 套打法没有一套稳定跑赢"只要空仓就做多"。** 把目标改成 1R 或 3R，这个结论也不变。只做多的版本大多和对照组接近或者更差；"RSI W 底只做多"表面上数字最好，但只有约 10 笔，而且换成 1R 或 3R 目标后，样本外就转为负数，说明只是噪音。
2. **做空那一侧在每一套打法里都亏钱**（比如假突破做空是 −0.14R，趋势回踩做空是 −0.42R）。2010 年以来美股长期向上，逆势做空的期望值是负的。
3. **投降反转很少出现**（16 年里只有 17 次），而且 2020 年 3 月 4 日和 10 日两次都是"抄在半山腰"、被止损，真正的底在 3 月 23 日。这正是他视频里警告的情况，说明规则本身就很难在当下把真底和假底分开。
4. **换算成买期权之后，所有打法的收益中位数都在 −20% 到 −46% 之间。** 正股上的一点点优势，被期权的时间价值和买卖价差吃掉了。

**局限**：他很多入场点是在 5 分钟、15 分钟图上找的，日线回测测不到这部分；期权价格是用 VIX 估算的，不是真实报价。

## 熊猫教练「高二进场 + EMA20 移动止盈」回测（`run.py h2`）

规则写在 `optbot/h2_backtest.py` 开头的注释里，要点如下：
- 趋势过滤：EMA21 > 55 > 144 多头排列才做多（空头排列才做空）。
- 入场：回调中第二次出现"本根 K 线高点突破前一根高点"（高二），下一根 K 线突破信号 K 的高点时入场。
- 止损：放在回调的最低点。
- 离场：在 EMA20 附近出现强底分型时，把止损上移到分型低点；整根 K 线落到 EMA20 下方时离场。
- 成本：每笔来回扣 0.02%。

数据：SPY、QQQ 的日线（2010–2026），以及 30 分钟线（2016–2026，各 35,338 根）。

| 场景 | 高二只做多：平均每笔 | 样本内 / 样本外 | 每笔冒险 1% 复利 | 同期买入持有 |
|---|---|---|---|---|
| 日线 | −0.015R（149 笔） | +0.03 / −0.05 | ×0.97 | SPY ×7.5、QQQ ×15.4 |
| 30 分钟，可过夜 | +0.140R（923 笔） | **+0.32 / −0.06** | ×2.9（最大回撤 −43%） | SPY ×3.9、QQQ ×6.0 |
| 30 分钟，当天平仓（最接近他的日内做法） | −0.063R（1,131 笔） | −0.10 / −0.02 | ×0.48 | 同上 |

做空那一侧（低二）在日线上是 −0.60R，在 30 分钟可过夜场景是 −0.13R，都在亏钱。

**和随机入场比**（同样的均线过滤和离场规则，随机挑入场点，重复 30 次）：
- 日线：高二只赢过 6/30 次；
- 30 分钟当天平仓：只赢过 10/30 次；
- 30 分钟可过夜：**样本内 30/30 次全赢**（+0.32R，随机平均 +0.15R），但**样本外只赢 7/30 次**（−0.06R，随机平均 −0.01R）。

**结论：**
1. "高二"这个入场时机，在 2016–2021 年的 30 分钟图上确实有过优势，但 **2021 年下半年以后就消失了**，样本外的表现甚至不如随机入场。这是典型的"历史上有效、之后失效"。
2. 他实际用的日内打法（当天平仓）全程都是负期望；日线也是负的。
3. 没有任何一个场景跑赢同期的买入持有。

**局限**：
- 他用的是 30 分钟判断趋势、5 分钟找入场，这里只能在 30 分钟上同时做这两件事；
- "强底分型""EMA20 附近"这些概念需要量化，我取了合理但唯一的一种写法；
- 没有换算成期权收益，因为正股层面已经没有正期望。

## VicAlpha「箱体底部低吸」回测（`run.py box`）

规则（视频默认参数）：中轨 = 20 日均线，上下轨 = 中轨 ±3%；收盘 ≤ 下轨 → 次日开盘全仓买入；收盘 ≥ 上轨 → 次日开盘卖出；不止损，只做多。复权价，来回成本 0.02%，空仓现金按 0 收益算。

| 2010-01 → 2026-11 | 笔数 | 胜率 | 在场时间 | 总倍数（年化） | 最大回撤 | 买入持有 |
|---|---|---|---|---|---|---|
| SPY | 34 | 79% | 41% | ×3.76（+8.2%） | −34% | ×7.46（+12.7%），回撤 −34% |
| QQQ | 49 | 80% | 33% | ×3.28（+7.3%） | −30% | ×15.36（+17.6%），回撤 −35% |

- 与随机入场比较（保持每笔持仓天数不变，随机放置入场日，重复 500 次）：SPY 排在第 94 分位，QQQ 排在第 78 分位。也就是说，"跌了再买"的时机确实比随机入场好一些。
- 样本内 / 样本外：SPY 年化从 +11.2% 降到 +5.6%（持有 +12.9%）；QQQ 从 +13.0% 降到 +2.4%（持有 +17.2%）。
- 参数敏感：同样是 20 日线，QQQ 用 ±3% 是 ×3.3，用 ±4% 是 ×8.6，用 ±5% 是 ×10.2。差别主要来自在场时间不同：区间越宽，越少触发卖出，就越接近买入持有。

**结论**：低吸的时机在美股指数上确实有一点效果，胜率也很高，但它只有三四成时间在场，所以总收益只有买入持有的一半甚至更少。又因为不止损，最大回撤并没有比持有更小（SPY 的一笔持仓拿了 235 天，扛过了 2020 年的暴跌）。

**加止损**（收盘价跌破买入价 X%，次日开盘卖出；默认止损后要等价格先收回下轨上方，再跌回下轨才能重新买入）：

| 年化 / 最大回撤 | 不止损 | 3% | 5% | 8% | 10% | 买入持有 |
|---|---|---|---|---|---|---|
| SPY | +8.2% / −34% | +6.2% / −20% | +8.5% / −27% | +7.0% / −27% | +7.9% / −27% | +12.7% / −34% |
| QQQ | +7.3% / −30% | +3.8% / −30% | +2.5% / −37% | +5.0% / −31% | +6.0% / −34% | +17.6% / −35% |

- 止损在 SPY 上能把回撤压低一些，但收益基本没有提高；在 QQQ 上收益普遍变差，回撤也没有变小。原因是止损之后价格往往又反弹回来，策略在来回止损中不断亏钱。
- 止损是按收盘价判断、第二天开盘才卖，所以跳空时实际亏损会超过止损线。例如设了 10% 止损，最差一笔 QQQ 仍然亏了 18.2%。
- 所有止损版本到了样本外（2018 年以后）都明显变差，全部跑输买入持有。
- 止损后"立即可以再买"的版本有几格看起来更好，比如 SPY 5% 止损的总倍数是 ×4.6。但这是在十几组参数里挑出来的，不能拿来当依据。

## 纪律锁：让程序替你守规则

你说过自己没法总是理性地执行纪律。纪律锁就是为这个准备的：**规则在冷静的时候定好，锁上之后，冲动时想改也改不了**。

| 命令 | 作用 |
|---|---|
| `run.py lock` | 锁定当前 `config.toml`，默认 30 天（`--days 60` 可以自定义天数） |
| `run.py discipline` | 查看锁定状态、累计盈亏、是否熔断 |
| `run.py unlock` | **申请**提前解锁，72 小时后才生效，这期间规则仍然锁着 |
| `run.py reset-breaker` | 复位亏损熔断（锁定期间不允许） |

锁定之后，程序会强制执行以下规则：

1. **改了配置就拒绝运行。** 止损线、预算、信号阈值，哪一项都不能临时调。
2. **亏损熔断。** 已实现亏损累计达到 `max_total_loss_usd`（默认 $28）后永久停止开新仓，之后赚回来也不会自动恢复。
3. **连亏暂停。** 连续亏 2 笔后，暂停开新仓 5 天，防止"想赢回来"的报复性交易。
4. **手动干预检测。** 如果你在 app 里手动买卖期权，导致券商持仓和机器人记录对不上，机器人会停止开新仓。
5. **止盈止损永远执行。** `STOP` 文件、熔断、暂停都只拦开新仓，不会拦平仓，所以不存在"扛单"的后门。
6. **无人值守实盘必须先锁定。** 把 `require_confirm_live` 改成 `false` 后，实盘就不用每笔输入 YES 了；但没锁定时程序会拒绝这样运行。

**推荐流程：**
1. 模拟盘跑满几周，看 `journal.csv` 和 `run.py discipline` 的结果。
2. 冷静的时候决定最终参数，写进 `config.toml`。如果要无人值守，把 `require_confirm_live` 改成 `false`。
3. 运行 `run.py lock`。
4. 运行 `run.py auto --live`，然后就交给它。

> 实话：任何程序都拦不住你直接关掉它，或者在 app 里手动下单。纪律锁做的事情，是让每一次冲动都需要多走几步、多等几天，并且留下记录。

## 第 7 步：实盘（真钱）

前提：入金和换汇完成、有价差权限、模拟盘至少完整走过一次「开仓 → 平仓」。

⚠️ 截至 2026-11-22，你的实盘账户是**现金账户（CASH）**。现金账户通常不能做一买一卖的价差，下单很可能被拒。先在 app 的「期权交易权限」里确认现金账户能做哪些期权策略。

```powershell
.\.venv\Scripts\python run.py once --live
.\.venv\Scripts\python run.py auto --live
```

- **每一笔实盘单**（开仓和平仓都算）都会在终端里列出明细，**必须输入大写 `YES`** 才会发送。
- 因为要确认，`auto --live` 跑到要下单时会停下来等你输入。不在电脑前就不会下单，这是故意设计的。
- **紧急停止**：在文件夹里新建一个名为 `STOP` 的空文件，机器人立刻不再下任何单。删掉文件即恢复。已经发出的挂单，去 moomoo app 里手动撤。

## 已知限制（还没用真实 OpenD 验证过的地方）

这套代码是按 moomoo OpenAPI 官方文档写的，离线测试全部通过，但**还没连过你的真实账户**。第一次跑模拟盘时请重点看：

1. **组合单的价格符号**：代码按「买入价差 = 正数净支出」下单。如果 OpenD 报价格错误，把报错发给我。
2. **组合单的成交回报**：如果 `status` 里挂单一直显示等待，但 app 里已经成交，说明 `order_list_query` 查不到组合单，需要改用 app 里的成交价。
3. **隐含波动率字段单位**：目前没有用到 IV 做决策，只是记录下来。
4. **澳洲账户的价差权限和行情权限**：只能在你的账户上实测。

本工具只是把视频里的公开规则自动化，不构成投资建议，盈亏自负。
