玉衡5.0 · 使用说明

【运行】
双击「玉衡5.0.command」。
程序会自动拉取 VIX、VXN、QQQ、布伦特、US10Y、美元指数的数据，
按你的工作流分析，在「报告」文件夹生成一份 Word 报告并自动打开。
第一次运行需要 1–2 分钟准备环境，之后每次十几秒。

如果第一次双击提示"无法打开"：在文件上点右键 →「打开」→ 再点「打开」，之后就能直接双击。

【报告内容】
一、结论速览：市场环境判断（避险 / 分歧 / 风险偏好）和综合分
二、警报：临近或突破关键位、单日异动、VXN−VIX 差值、传导链共振
三、六指标概览：最新值、1/5/20日变动、相对20日均线、1年分位、状态
四、按看盘顺序分析：情绪 → 利率与资金 → 通胀 → 价格确认
五、传导链检查：每个环节今天和近5日是否按典型方向联动
六、近半年走势图（含你设置的关键位）
—— 第二个平台：自选股 ——
七、自选股总览：收盘、涨跌、RSI14、MACD 状态、量比、关键位、相对板块强弱
八、个股信号：RSI 超买超卖/回穿/背离、MACD 零轴上下金叉死叉、放量、关键位突破跌破、与板块背离
九、板块联动：板块ETF强弱、成员是否同涨同跌（相关系数）
十、个股档案：业务、优势、催化剂、利好利空（你填写）+ 财报日、新闻标题（自动）
—— 第三板块：交易机会（第一页「结论速览」最后一行有汇总）——
十一、交易机会：A/B/C 分级总览；事件博弈（周五押周末）；日内①消息爆发；波段/隔夜（扫荡、暴跌回归）；
      日内② 开盘前 SMC/ICT 地图（前日/盘前高低、午夜开盘价、上下方流动性、未回补 FVG）；观察名单；风控提醒
      每个机会都写明触发条件、失效位、目标、盈亏比，以及符合规则的期权合约和建议张数

【什么时候运行】
盘前报告建议在美股开盘前 30–60 分钟双击运行：
悉尼冬令时（美国冬令时期间）开盘是凌晨 1:30，建议 0:30–1:00 运行。
运行前先打开 OpenD 并登录，盘前/夜盘价格和期权链才读得到。

【盘中监测（开盘后弹窗提醒）】
开：双击「开始盘中监测.command」　关：双击「停止盘中监测.command」，或直接关掉监测窗口。
· 只在美股常规交易时段扫描（美东 9:30–16:00，悉尼冬令时为凌晨 1:30–8:00），开盘前打开会自动等待。
· 默认每 3 分钟用 moomoo 实时数据重跑一遍第三板块；出现 B 级以上的新机会、机会升级（C→B、B→A），
  或「待扫」的机会真正触发（越过关键位后收回）时，弹出红色警示框并响铃，必须点掉才消失。
· 同一个机会当天只提醒一次（升级或触发时再提醒）；每条提醒都记在「报告/盘中监测_日期.txt」。
· 第一次开启时系统可能询问「终端」能否控制「System Events」，请点「好」，否则弹窗无法置顶。
· 监测期间电脑不会自动睡眠；需要 OpenD 保持登录。
· 扫描间隔、提醒级别、提示音在「设置.json → 盘中监测」里改（第一次开启后会自动出现这一项）。

【用 TradingView 的数据】
把 TradingView 导出的日线 CSV 放进「TradingView数据」文件夹（导出方法见里面的说明），
程序会优先用这些数据，数值和你看盘时一致。
没放或超过 3 天没更新的品种，自动改用 Yahoo 数据。报告末尾「数据来源」会逐个标明。
有效天数可在「设置.json」的 TradingView_CSV_有效天数 里改。

【自定义个股的线和参数】
打开「个股设置.xlsx」（双击即可，用 Excel / WPS / Numbers 都行），改完保存：
· 关键位：你画的压力位、支撑位，每条线一行
· 个股参数：板块、对比ETF、放量倍数、RSI 阈值、临近距离
· 公司档案：基本业务、核心优势、催化剂、利好利空、你的观点
· 期权与机会：单张价格上限、delta 区间和底线、平值范围、各打法到期天数、暴跌/跳空阈值、分级、事件博弈预算
详细说明见表格里的「说明」页。

【连接 moomoo（自动读取自选股和价格提醒）】
1. 下载并安装 moomoo OpenD：https://www.moomoo.com/download/OpenAPI （选 Mac 版图形界面 OpenD）
2. 打开 OpenD，用你的 moomoo 账号登录，保持它在后台运行（默认端口 11111，不用改）
3. 双击「玉衡5.0.command」，程序会自动读取：自选股列表（期权会自动跳过）、你设的价格提醒、日K
没开 OpenD 也能运行：自选股用「个股设置.xlsx」里的列表，日K 改用 Yahoo。
OpenD 只用来读行情，程序不会下单或碰你的交易。
自选分组默认读「全部」，想读别的分组，在「设置.json」的 moomoo → 自选分组 里改名字。

【修改宏观关键位】
用文本编辑打开「设置.json」，改数字后保存，下次运行生效。
US10Y、DXY、布伦特、QQQ 的关键位是示例值，请按你自己画的关键位修改。
QQQ_下方支撑 填 0 表示不启用。
「生成后自动打开报告」改成 false 就不会自动打开。

【出错时】
看「报告/错误日志.txt」，把内容发给 Claude 即可。
常见原因：网络不通，或 Yahoo 接口变动（程序每 30 天自动更新一次接口）。

数据来自 Yahoo Finance，与 TradingView 可能有细微差异或延迟。
报告按固定规则生成，仅用于辅助复盘，不构成投资建议。

【网站分享（给同事看报告和盘中提醒）】
开启后，每次生成报告都会自动：转成网页 → 上传到 Cloudflare Pages → 把摘要推送到工作群；
盘中监测出现新提醒时，也会推送到群并更新网站的「盘中提醒」页。
· 设置在「设置.json → 网站分享」，填好后把「启用」改成 true。
· 上传网页需要电脑装有 Node.js（https://nodejs.org，选 LTS 版）。
· 网页文件在「网站」文件夹里；只保留最近 60 份（可改「保留报告份数」）。
· 双击「测试网站和推送.command」可以用最新报告测试一次。
· 网站一定要用 Cloudflare Access 设登录（只允许同事邮箱），否则任何人都能打开。
· 出错不影响报告和弹窗本身，详情写在「报告/错误日志.txt」。

【Discord 机器人（同事在频道里发命令）】
开：双击「启动机器人.command」（这个窗口要一直开着，电脑不能关机）　关：关掉窗口
同事在频道里发：快讯 / 给我报告 / 开启监测 / 停止监测 / 状态 / 帮助
· 设置在「设置.json → Discord机器人」：填机器人令牌，「启用」改成 true。
· 允许的频道ID：只在这些频道响应（留空 = 所有频道）；允许的身份组：只让这些身份组的人用（留空 = 所有人）。
· 同事要报告时，你电脑不会弹出 Word；报告摘要和 Word 文件直接发到频道。
· 机器人的记录在「报告/机器人日志.txt」。
· 自动快讯：每个美股交易日悉尼时间凌晨 1:00 自动把「快讯」发到频道。时间在「设置.json → Discord机器人 → 自动快讯」里改，不想要就把「启用」改成 false。

【板块分类】
每只股票属于哪个板块、用哪只 ETF 对比板块强弱，在「个股设置.xlsx → 个股参数」的「板块」「对比ETF」两列改。
目前的板块：芯片设计 / 存储 / AI基建/光通信 / 互联网/流媒体 / 软件/云 / 电商/消费科技 / 电动车/自动驾驶 / 航天/工业 / 必需消费 / 指数/债券ETF。
· 报告第七节按板块分组，第九节列出每个板块的强弱；快讯的自选股部分按板块分组。
· 板块集体异动：同一板块至少 2 只、75% 以上同向、平均涨跌超过 2.5% 时，快讯「今日要点」会写出来，盘中监测会弹窗并推送到 #监测。
  阈值在「设置.json → 盘中监测」的「板块异动_平均涨跌幅%」「板块异动_同向比例」里改；不想要提醒就把「板块异动提醒」改成 false。
· 新建板块直接在表格里写新名字就行，会排在最后显示。

【夜盘复盘】
在 #快讯 发「夜盘」：用 moomoo 夜盘 1 分钟K 复盘最近一个夜盘（美东 20:00–次日 04:00）。
内容：大盘和自选股夜盘涨跌、最活跃的股票、1 分钟异动（时间、幅度、放量倍数，并附同一时间的快讯）、
是否扫过前一天的高点 / 低点、开盘前要盯的位置（夜盘高 / 低、VWAP、午夜开盘价）。
每个美股交易日夜盘结束后（美东 04:10，悉尼约 20:10）自动发到 #快讯，在「设置.json → Discord机器人 → 自动夜盘复盘」里改。
需要 OpenD 登录，并且 moomoo 账号有美股夜盘行情权限。

【机会 A/B/C（按 2026-11-06 交接说明）】
和原来的交易机会（扫荡、暴跌回归、消息爆发、事件博弈）并存，提醒里标「机会A/B/C」。只读监测，供人工决策，不下单、不给仓位。
· 机会A：H1 到达预设区域 → M15 十字星 / 吞没 / FVG → M5 收盘严格越过前根整根高低点
· 机会B：H1 顺势到关键位 + 当前 H1 潜在转弱 + M5/M15 的 RSI14/MFI14 背离（必需）→ M5 实体确认（只在常规时段）
· 机会C：开盘 90 分钟内大跌 → M5 RSI<30、MFI<20 → 反弹（形状需人工确认）
· 区域 = 个股设置.xlsx 的关键位 + moomoo 价格提醒 + 期权墙（「期权墙」页手动录入优先，否则用 moomoo 期权链 OI 自动算，每天一次）
· 数据：moomoo M5（含盘前盘后），H1 / M15 由 M5 合成；只用已收盘K线
· 状态：观察候选 / 条件成立待人工决策 / 候选失效 / 数据不足；同一候选只在状态变化时提醒
· 参数在「设置.json → ABC机会」；「待标定」的数值先用默认值，提醒里会标出来
· 双击「ABC回放检查.command」：用最近 2 天真实行情逐根回放，结果写在「报告/ABC回放_日期.txt」，请对照图表核对信号时间

【Grok 盘前雷达（开盘爆发用）】
每个美股交易日美东 8:40（悉尼约 00:40）跑一次，约 5 分钟出结果：用 Grok 搜你关注的 54 个 X 账号（按 10 个分类、分 7 组，3 组同时搜），覆盖前一天收盘到当时的帖子。
· 简讯 → #快讯：今日倾向、关键驱动、开盘爆发关注、最重要的 5 条帖子
· 报告 → #报告（附 Word，同时存进「报告」文件夹）：结论速览 / 逐只股票（发生了什么、核心观点、对股价的影响、谁看涨谁看跌）/ 按账号类别 / 全部帖子
· 在 #快讯 发「雷达」可随时手动跑一次
· 设置在「设置.json → Grok盘前」：API密钥、启用、账号分组（加减账号在这里改，每批最多 20 个）、每日费用上限（默认 5 美元）
· 防编造：帖子链接必须出现在 Grok 本次搜索结果里，发帖时间由帖子编号计算；谁看涨谁看跌由程序从已核实帖子汇总

【Reddit 散户监测（盘前）】
在 #散户 发「开启散户监测」：每个美股交易日盘前（美东 4:00–9:30，悉尼约 20:00–01:30）每 5 分钟扫一次 r/wallstreetbets、r/options、r/stocks 的热度（ApeWisdom，免费），一直开着直到发「停止散户监测」。
· 🔥 热度飙升：自选股提及次数是 24 小时前的 3/5/10 倍（至少 20 次），或冲进 WSB 前 10；升级时再提醒
· 🐎 新黑马：自选股以外的股票冲进 WSB 前 20、至少 50 次、5 倍以上
· 触发后用 Grok 读 Reddit 帖子：散户偏多/偏空、押 call 还是 put、情绪是否亢奋，附代表帖子链接
· 标签：🟢共振 / 🟠过热（易高开低走）/ 🟣逼空风险 / ⚪观察
· 「散户」看热度榜；「散户 TSLA」看单只股票的散户情绪
· 阈值和每日费用上限（默认 2 美元）在「设置.json → Reddit散户」里改；Grok 用「Grok盘前」的 API 密钥

【2026-11-10 更新：消息爆发分级、建议张数、提醒记录】
· 消息爆发不再一开盘就标 B 级：开盘前、以及开盘后前 15 分钟只观察（显示为 C 级、不给合约）。
  之后止损改按今日低点（做空按今日高点）算，不再把整个缺口算进风险；目标至少离现价 0.5 倍 ATR；
  盈亏比达标（B 级 ≥ 2、A 级 ≥ 3）才分级提醒。缺口回补过半就不再提示顺势机会。
· 建议张数：在「设置.json → 工作流 → 单笔最大亏损_美元」填一个数字（比如 300），提醒里会多一行建议张数
  （张数 = 单笔最大亏损 ÷ 每张预计亏损；每张预计亏损 ≈ delta × 入场价到失效位的距离 × 100，加一成余量）。
  留空 null 就不给张数。
· 盘中监测重启后不再重复弹出当天已经提醒过的机会（记录存在 程序/data/trading.db）。
· 每条机会和每次提醒都记进数据库（signals / signal_events 两张表），以后复盘和统计胜率用。
· 扫描间隔改回 3 分钟（设置.json → 盘中监测 → 扫描间隔_分钟）。
· 想退回改动前的版本：双击「恢复到改动前.command」。

【2026-11-10 更新（二）：交易日志、信号结果、收盘复盘、K线入库】
· 收盘复盘：机器人开着的话，每个交易日美东 16:20（悉尼冬令时约早上 8:20）自动做一次，发到 #报告：
  ① 把研究名单里的 1 分钟 / 5 分钟 / 日线 K 线存进 程序/data/history.db
  ② 从 moomoo 只读拉最近 7 天的成交（不需要交易密码，程序不会下单）
  ③ 把成交合并成一笔笔交易，和当天的信号对照，标成「按信号 / 信号未达标 / 计划外」
  ④ 用 1 分钟 K 线判断每条信号先到目标还是先到失效位
  也可以在 Discord 发「复盘」，或双击「收盘复盘.command」。
· 盘前计划：开盘前在 Discord 发「计划 偏多，最多 3 笔，QQQ 跌破 500 认错」。复盘时会对照方向和笔数。
  「设置.json → 工作流 → 盘前计划强制填写」改成 true 后，当天没写计划之前信号只记录、不弹窗（默认 false）。
· 补原因：复盘会列出不是按信号做的交易，在 Discord 发「原因 NVDA 看到突破忍不住追了」补一句。
· 研究名单：「设置.json → 工作流 → 研究名单」填代码，例如 ["NVDA", "TSLA", "META"]；留空 = moomoo 自选全部美股。
· 回填长期 K 线：收盘后双击「回填历史K线.command」，或在 Discord 发「回填历史」。第一次要几十分钟。
· 检查连接：双击「检查复盘连接.command」，看 OpenD、交易账户、成交、K 线能不能读到（不写数据，盘中也能用）。

【2026-11-10 更新（三）：形态统计（历史胜率）】
· 用历史 K 线把现有打法（扫荡、暴跌回归、消息爆发）逐日回放，统计每个形态在每只股票上「先到目标还是先到失效位」。
  回放用的是和实盘完全相同的判断函数，每天只用当时已经收盘的 K 线，不会偷看未来。
· 怎么跑：收盘后双击「回填历史K线.command」（补完会自动统计），或在 Discord 发「回填历史」。
  以后想用最新数据重算：双击「形态统计.command」，或 Discord 发「形态统计 重算」。只发「形态统计」= 看上次的结果。
· 弹窗里会多一行：「历史：NVDA 296 次，胜率 21%（目标 31 / 失效 115）；全部股票 1507 次，胜率 18%」。
  样本少于 20 次显示「样本不足」。不想要就把「设置.json → 工作流 → 弹窗附历史胜率」改成 false。
· 怎么看：胜率 = 到目标 ÷（到目标 + 失效）。结果里括号是前 70% / 后 30% 时间段的胜率，两段差很多说明不稳定。
  只有日线可用的年份，同一天里目标和失效位都碰到的记「不确定」，不计入胜率。
  历史级别不含「大环境」那一层，历史上最高只到 B 级。

【2026-11-10 更新（四）：今日环境卡（AI 盘前判断）】
· 每个交易日美东 8:50（悉尼冬令时约 00:50），机器人把全部盘前资料交给 AI，生成「今日环境卡」发到 #快讯：
  主线、大盘方向（和规则结论并排，标明一致 / 不一致）、各板块方向、特别关注的个股、今日事件、矛盾点、今天避免什么。

· 每天盘前报告和收盘复盘时自动生成「数据/今日/日期/预案.md」，策略库页面最上面也有「今日预案」。逻辑照《交易的本质》的三个问题：
  ① 凭什么有优势：每只股票先看现在是哪种行情（强势上涨 / 温和上涨 / 窄幅震荡 / 宽幅震荡 / 温和下跌 / 强势下跌 / 恐慌急跌），再从 34 条策略里找「在这只股票、这种行情里，2022 年以前和以后都跑赢拿着不动、并且都赚钱」的。
     - 这条策略在这种行情里，在至少 30% 的股票上也成立 → 「检验通过」，按今天的仓位做；
     - 只在这一只股票上成立 → 「试仓级」，可能是运气，最多 1 张，走不出来就砍；
     - 都没有 → 这只今天不做。
  ② 值不值得冒险：列出挑中策略的平均每笔、胜率、最差一笔、止损参考；全期平均每笔为负的不选。
  ③ 怎么兑现：写成「如果……就……」。例如「如果大盘 QQQ 是恐慌急跌 → 每笔最多 2 张、最多 2 笔、亏 $300 停手」「如果 AMD 还是恐慌急跌 → 试仓多 1 张」。
· 大盘行情 → 当天风险上限（设置.json → 预案 → 行情风险，可以改，但只能比基本限制更严，改了写修改记录）：
  强势上涨 / 温和上涨 / 窄幅震荡：4 张、3 笔、$600；宽幅震荡 / 温和下跌：3 张、3 笔、$450；强势下跌：3 张、2 笔、$450；恐慌急跌：2 张、2 笔、$300。
  这是按波动大小缩仓的风险偏好，没有回测过。盘前报告新建纪律设置时会自动按这个收紧。
· 纪律程序新增：同一个合约同时拿着的张数超过「每笔最多张数」会弹窗（加仓算在一起）。
· 如实说（2026-11-23 第一次跑）：每种行情里，最好的策略也只在 1–5 只股票上成立（平均每条策略只有 1–5%），没有一条达到「跨股票 30%」。今天的预案是：0 只检验通过，5 只试仓级（AMD、AVGO、NBIS、NOK 多，NFLX 空），其余不做。挑不出来是正常的结果，不是程序坏了。要知道预案有没有用，得记 40 天以上，按预案做和不按预案做的分开算。
· 这些都是日线规则：决定今天做哪只、什么方向、冒多大风险；1 分钟的入场点还是按打法 A / B。
