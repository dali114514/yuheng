# 给 Claude 的使用说明（玉衡5.0 · 数据文件夹）

这个文件夹是交易者和 Claude 一起用的工作区。交易者在悉尼，做美股期权，看 1 分钟图。程序只读行情、不下单；所有交易由交易者手动下单。完整规则见上一层的 `CLAUDE.md`。

- 个人策略 B：VWAP 回踩（原「打法 A」）：C1 / C2 / C3（开盘第一段、回调、第二段；前 5 根不做，第 6 根是信号，C2 回踩 VWAP 后等确认组合再进）。
- 个人策略 A：爆发（原「打法 B」）：大实体阳线收盘站上 VWAP 追多，目标前高；必须和 QQQ 同向、前高至少 $1.5 远（回测：和 QQQ 反向时稳定亏钱）。
- 仓位方案「广撒网滚仓」（原「打法 C」）：广撒网试仓 1 张，止损 = 权利金亏 min(0.5, 50%)；15 分钟不到 +0.5R 就砍；≥ +1R 且正股在 VWAP 有利一侧先挪保本再加（越加越少）；≥ +2R 止损挪 +1R；连亏 3 笔停手。未回测。盯盘界面顶上的「作战面板」实时盯持仓（`程序/roll.py`）。盘中被问持仓时先看这个面板的状态。
- 仓位：每次 3–4 张期权；止损 = 每张权利金亏 0.5 就走（平值期权约等于股价逆向 $1）。
- `基本纪律.md`：长期有效的纪律，每天的 `打法和纪律.md` 开头都要列出，盘中回答「能不能进」时逐条核对。

## 文件夹
- `说明.md`：数据格式（时间是美东，分钟 K 的时间是结束时间）。
- `冷数据/股票/总览.md`、`冷数据/股票/<代码>/摘要.md`：先读这两个；原始 K 线在同一文件夹的 CSV。
- `冷数据/信息面/`：按类别和日期的新闻；`按股票/<代码>.md` 是单只股票最近 30 天。
- `今日/<日期>/`：盘前资料.md（程序整理）、夜盘.md、盘前分析.md（Claude 写）、打法和纪律.md（定稿）、纪律设置.json（程序读）、复盘.md。
- `热数据/`：盘中每分钟更新。状态.md、1分钟/<代码>.csv、纪律.md（后面附着基本纪律）、盘感_<代码>_<时间>.md。

## 交易者说「开始今天」时
1. 读 `今日/<日期>/盘前资料.md`（一份里已经有大盘日程、夜盘、全部自选股、Kill Zone 数据、C2 分股票回测、个股消息、散户情绪、推特、宏观）。还没生成就跑 `python3 程序/today.py --full`。
2. 写 `今日/<日期>/盘前分析.md`：大环境、今天偏向、建议观察的 3–5 只（理由、关键价位、认错价）、建议激进 / 标准 / 保守。
3. 和交易者讨论。定稿后写 `打法和纪律.md`（给人看）和 `纪律设置.json`（格式见同文件夹的 `纪律设置_说明.md`），交易者确认后把「状态」改成「已锁定」。
4. 锁定后程序（guard.py）按它弹窗卡纪律，早盘 C2 监测和热数据只盯观察名单 + QQQ、SPY。

## 盘中交易者提问时
- 先读 `热数据/状态.md` 和 `热数据/纪律.md`。
- 「现在怎么样 / 能不能追」：运行 `arch -arm64 程序/.venv/bin/python 程序/engine.py <代码>`（盘感引擎），结果同时存到 `热数据/盘感_<代码>_<时间>.md`。再对照 `冷数据/信息面/按股票/<代码>.md` 和当天新闻判断。引擎的走前验证显示预测力很弱，结论以「观察」为主，要如实说。
- 同时读 `热数据/形态.md`（震荡区间、今天出现的信号K / 组合K、ABC 级别和历史概率）。引擎会画 `热数据/盘感_<代码>_<时间>.png`（今天的 5 分钟K + 最像的 10 天叠图）。
- 形态的历史概率都在 48%–52%（和基准差不到 2 个百分点），震荡突破扣成本后约 0R（见 `报告/形态概率_*.md`）。级别是纪律五条的核对结果，不是胜率；要如实说。
- 盘前看 `今日/<日期>/期权墙.md`（看涨墙、看跌墙、净 gamma），盘中 `热数据/状态.md` 末尾有资金流向；两者都没回测过，只当位置和背景。
- 回答要短：现在什么情况、按今天的打法该做什么（等 / 可以进 / 认错 / 不做）、哪种情况说明判断错了。
- 不在名单里的股票：说明今天的纪律是「只做名单内」，不替交易者找理由做计划外的交易。
- 看到 `热数据/纪律.md` 里有「方向相反」等触发记录，回答时要先指出来。
- 盘中改纪律：先写明理由，加进纪律设置.json 的「修改记录」。

## 收盘后
- 和交易者一起写 `今日/<日期>/复盘.md`：每笔交易是否在计划内、纪律触发记录（热数据/纪律.md）、判断对错、打法要改什么。

## 运行环境
- 这个文件夹在交易者的 Mac：`~/Desktop/玉衡5.0/数据`（2026-11-24 起文件夹从「赚钱小助手」改名为「玉衡5.0」）。程序在 `../程序`，K 线库 `../程序/data/history.db`。
- 分析脚本需要 numpy / pandas。

## 玉衡策略库（2026-11-23 起）
- 交易者问某只股票「现在是什么行情 / 哪些日线策略在这只股票上管用 / 今天有没有日线信号」时，读 `程序/data/策略库/<代码>.json`（单只）或 `程序/data/策略库/index.json`（汇总，`summary.strategies` 是每条策略在全部股票上的表现，`summary.signals` 是今天触发的信号）。页面在 http://127.0.0.1:8760/lib。
- 每天收盘复盘时自动重算；手动：`arch -arm64 程序/.venv/bin/python 程序/stratlib.py`（加代码只算那几只）。
- 如实说：34 条日线策略在 31 只股票上，相对买入持有的年化中位数全部为负；样本内外都跑赢持有的最多 2 只股票。日线规则和他日内 1 分钟的个人策略 A / B 和广撒网滚仓是两回事，只当大方向和背景。

## 今日预案（2026-11-23 起，`程序/playbook.py`）
- 「开始今天」时先读 `今日/<日期>/预案.md`：每只股票的行情、按行情挑中的策略（检验通过 / 试仓级 / 不做）、大盘行情对应的张数 / 笔数 / 单日亏损上限。按《交易的本质》三个问题讨论：有没有优势 → 值不值得冒险 → 写成「如果……就……」锁定。
- 观察名单优先从「检验通过」里选；「试仓级」最多 1 张；预案说不做的，交易者要做先请他说明理由。
- 风险上限在 `设置.json → 预案 → 行情风险`，只能收紧；改要写修改记录。

## 日内策略库（2026-11-24 起，`程序/intraday.py`）
- 预案主线改成日内：`预案.md` 的「日内：按开盘类型」部分，每只股票按今天开盘是哪种（大幅低开 / 低开 / 平开 / 高开 / 大幅高开）走对应分支；不在表里的 = 不做。盘中先看开盘类型，再回答「能不能进」。
- 止损跟着分支里的「策略 + 止损」，不再固定每张 0.5，没有单笔美元上限；张数按大盘行情上限。用实时 Delta 换算每张亏损（预案里有，没有就用 moomoo 期权快照算）。
- 如实说：随机入场每笔约 −2% 到 −8%（权利金），大部分组合为负；明显好于随机的只有大幅低开的日子。
- 剥头皮版（`程序/scalp_bt.py`，2026-11-24）：同样的入场改成几分钟内小目标出场，扣散户成本后大票全部为负，期权每笔 −2% ~ −6%；交易者想剥头皮时如实说，见 `报告/散户剥头皮回测_2026-11-24.md`。
