# 三层策略库回测（入场 × 止损 × 止盈，多空分开）· 2026-11-24

程序：`程序/intraday.py`（v5.4.0）。34 只股票，2019-01 起 1 分钟K；9:36–11:00 开仓，最晚收盘平；换算成期权（平值、约 3 天到期，Black-Scholes，时间损耗按交易分钟，买卖各扣 1% 价差）。样本内 2019–2023，样本外 2024 起。数字是**每笔的权利金收益率**，全部股票按笔数加权。

- 入场 12 条（含个人策略 A：爆发、个人策略 B：VWAP 回踩、新加的「缺口延续」和随机对照），**每条都分做多 / 做空**
- 止损 7 种：权利金固定比例、0.1 / 0.2 倍 ATR、结构、VWAP 反穿、前 5 根移动、11:00 时间止损
- 止盈 8 种：2R、前高 / 前低流动性、斐波那契 1.0 / 1.272 / 1.618 / 2.0 / 2.618、拿到收盘
- 每只股票 12 × 2 × 56 = 1,344 组。全部重算约 100 秒。
- 和旧版对得上：同样定义的组合（例如 VWAP 回踩 + 结构止损 + 2R、爆发做多 + 结构 + 2R）结果和旧版一模一样。

## 结论（先说）

1. **全部股票合起来看，没有一组「入场 + 止损 + 止盈」是赚钱的。** 每条入场挑最好的出场，样本内和样本外仍然都是负的。最好的几组：个人策略 B 做多 + 11:00 时间止损 + 拿到收盘（内 −1.3% / 外 −0.8%）、10 点趋势延续做空 + 11:00 + 斐波那契 1.272（−0.7% / −0.9%）。随机入场最好的出场约 −2%。所以策略比随便进好一点（大约 0.5–1 个百分点），但不够付期权成本。
2. **个人策略 A（爆发）**：做多最好 −1.8% / −1.0%（0.2 倍 ATR + 斐波那契 1.272），做空（镜像）最好 −2.0% / −2.5%。**做空比做多差**，和上次结论一致。
3. **个人策略 B（VWAP 回踩）**：做多明显比做空好（全部出场平均 −2.3% vs −3.4%）。
4. **斐波那契止盈**：档位越近越好——1.0 平均 −2.2%、1.272 −2.4%、1.618 −2.8%、2.0 −3.1%、2.618 −3.5%、拿到收盘 −3.8%。原因是期权每分钟都在掉时间价值，早点走比等大目标好。**斐波那契 1.0 是 8 种止盈里最好的**，但和「前高 / 前低」（−2.4%）差不多——1.0 档本来就接近今天的高低点。
5. **止损**：前 5 根移动止损（−1.9%）和 11:00 时间止损（−1.9%）最好，但随机入场用这两种也是约 −2.0% / −2.3%，**它们好主要是因为拿得短，不是因为选得准**。结构止损最差（−4.1%）。
6. **跨股票真正多于随机的**，还是集中在开盘有大缺口的日子：
   - 大幅低开 · 做多：VWAP 收复 + 11:00 时间止损，8/20 只股票样本内外都赚（随机最多 7%）
   - 低开 · 做空：5 分钟开盘区间突破 + 11:00 时间止损 + 拿到收盘，13/29 只（随机最多 3%）
   - 平开、高开的日子，最好的组合也只有 3–7 只股票成立
7. **预案能挑出来的变多了，要打折看**：34 只 × 5 种开盘 × 2 个方向 = 340 个位置里，检验通过 46 个、试仓级 122 个（旧版 170 个位置里 18 / 49）。比例略高，主要因为每只股票可选的组合从 99 组变成 1,344 组，碰巧样本内外都赚的机会更多。**挑的时候已经用到了样本外，所以没有真正没看过的数据来检验这些挑法**——下一步仓位层回测会改成「只用 2019–2023 挑、2024 起检验」，看挑出来的东西在没看过的数据上还剩多少。

## 如实说

- 期权收益是模型估的（没有历史期权报价）。开盘后隐含波动率下降、真实价差比 1% 大的时候，结果会更差。
- 同一天的股票彼此相关，「X/Y 只股票成立」的不确定性比看起来大。
- 组合越多越容易挑到运气。预案的门槛没有放松（样本内外都赚 + 跨股票 ≥ 30% 且比随机高 15 个百分点才算检验通过），但随机入场每天都有信号、样本大、很少碰巧通过，而策略信号少、更容易碰巧通过，所以「比随机高」这把尺子本身偏松。
- 下一步（仓位层）：在挑中的组合上模拟「只做 1 张 / 广撒网滚仓 / 固定美元风险 / 金字塔 / 分批出场 + 熔断」，并改成只用 2019–2023 挑、2024 起检验。
